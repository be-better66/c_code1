==============================================================
串口手柄 -> 虚拟 Xbox 360 手柄（方案二）使用说明
==============================================================

【它是干嘛的】
把你的 STM32 串口手柄（摇杆+按键+马达）变成 Steam 认得的
"Xbox 360 手柄"。Steam 游戏会把它当真正的手柄，摇杆是模拟量
（有力度/线性），还能用 Steam Input 改键、支持震动。

【需要装什么（一次性）】
1. ViGEmBus 驱动（免费开源，装一次即可）：
   下载地址：https://github.com/ViGEm/ViGEmBus/releases
   下载 ViGEmBus_Setup_x64.exe（或对应版本），一路下一步装完。

2. Python 3（如果电脑没有）：
   到 https://www.python.org/downloads/ 下载安装。
   ⚠ 安装时一定要勾选 "Add Python to PATH"！

3. 两个 Python 库（打开命令行执行）：
       pip install vgamepad pyserial

   （本文件夹里的 requirements.txt 就是这两个库的清单）

【怎么用】
1. 用记事本打开 serial_to_xbox.py，把第 30 行左右的
       PORT = "COM11"
   改成你手柄的串口号（设备管理器里 CH340 显示的那个）。

2. 插好手柄（供电 + 串口都接好）。

3. 双击运行 serial_to_xbox.py（或命令行运行）：
       python serial_to_xbox.py

4. 看到 "已连接 COMxx" 就说明成了，虚拟手柄已创建。

5. 打开 Steam 游戏，进游戏的"控制器/手柄设置"里，能看到
   "Xbox 360 Controller" 就说明成功，直接玩。

6. 退出脚本按 Ctrl+C。

【按键映射（默认）】
摇杆：
   左摇杆 X/Y  -> 手柄左摇杆（移动）
   右摇杆 X/Y  -> 手柄右摇杆（视角/瞄准）

左按键模块（5 键）：
   0V    -> A
   0.47V -> B
   1.0V  -> X
   1.64V -> Y
   2.4V  -> LB（左肩键）

右按键模块（5 键）：
   0V    -> RB（右肩键）
   0.47V -> Start（菜单）
   1.0V  -> Back（背包/地图）
   1.64V -> 按左摇杆 L3
   2.4V  -> 按右摇杆 R3

（这些在 serial_to_xbox.py 里的 LEFT_KEYS / RIGHT_KEYS 里改）

【怎么改按键 / 改摇杆方向】
- 改按键：在 LEFT_KEYS / RIGHT_KEYS 里把电压对应的按钮换成别的
  （按钮名形如 vg.XUSB_BUTTON.XUSB_GAMEPAD_A 等）。
- 摇杆方向反了：在 main() 里对应的 norm(...) 前面加负号。
  注意：当前 Y 轴（上下）已经按你的手柄做了反向处理（脚本里写的是
  -norm(y1)、-norm(y2)），所以"上推 = 上"是对的。若哪天想改回来，
  把那个负号去掉即可；若 X 轴（左右）也反了，同样给 norm(x1)、norm(x2) 加负号。

【重要说明】
1. 下位机（STM32）只在"摇杆偏离/按键按下"时才发数据，松手就不发了。
   所以脚本用了一个 0.2 秒的超时：超过 0.2 秒没收到数据就自动把
   摇杆归中、按键松开。这是为了让"松手"能被识别。

2. 想让手感更好（摇杆归中零延迟、震动更跟手），建议把 STM32 固件
   改成"每个周期都发数据"（不管偏不偏离都发）。需要的话我可以帮你改。

3. 震动反馈（当前版本还没做，属于下一步，需要两步配合）：
   a) 脚本侧：读取游戏发给虚拟手柄的震动值，再通过串口发给下位机；
   b) 下位机侧：把"收到 YM1: 就震 10 秒"改成"收到就震、收到停止就停"。
   需要的话我可以帮你补上这两块。
